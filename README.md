# lab-assets

研究室 AI 閘道站（千問大小姐）的網站靜態資產。全部為縮放重編碼後的版本，非原始解析度。

| 檔 | 尺寸 | 用途 |
|---|---|---|
| img/logo.png | 128×128 | 站內徽標（原圖 1254×1254，實際顯示只有 28×28） |
| img/hero.webp | 1200×675 | 首頁橫幅 |
| img/stand.webp | 800×1433 | 立繪 |
| img/meme.webp | 830×1106 | 表情插畫 |

## 著作權與出處

站內插畫（角色立繪與相關圖）由 **ZipZipPipe** 創作，並非本研究室原創。原作者於公開貼文表示「發出來方便大家使用」，未附正式授權條款，因此本處僅以非商業、研究室內自用之方式重製與放置，並保留此署名。如需商業使用，請先取得原作者授權。

重製理由：原圖散佈在多個第三方圖床（含 Google 搜尋縮圖與表情包站），連結一失效就會造成站內破圖；且原圖解析度遠超顯示需求，對頻寬不友善。

本 repo 與 Qwen、ZipZipPipe 無隸屬或背書關係。
